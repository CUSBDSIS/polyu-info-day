# BDSIS at PolyU Info Day 2026

The card generator for the Bachelor's Degree Scheme in Interdisciplinary
Studies (JUPAS JS3000). A visitor picks two or three disciplines, types a
name, and the page lays out a personalised 86 × 54 mm card to save as a
print-ready PNG. Everything runs in the browser; nothing is sent anywhere.

Published with GitHub Pages at https://cusbdsis.github.io/polyu-info-day/

The generator is authored in the BDSIS brand-system repository; run
`tools/sync-from-branding.sh` to bring this copy up to date, then commit.
